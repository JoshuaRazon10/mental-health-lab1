User Stories

1.  As a stressed user, I want to access guided breathing exercises, so that I can quickly calm myself down.
2.  As a wellness seeker, I want to **read about the importance of sleep, so that I can improve my healthy habits.
3.  As a new visitor, I want to see a clear navigation menu, so that I can easily find the topics I'm interested in.
4.  As an anxious user, I want to generate a supportive AI message, so that I can feel a moment of encouragement.
5.  As a returning user, I want to find simple relaxation tips, so that I can practice mindfulness without needing an app.

6.  As a stressed user, I want to click on the "Box Breathing" guide, so that I can follow the step-by-step instructions.
    Acceptance Criteria:
    Given I am on the Breathing Exercises page,
    When I click the "Box Breathing" link,
    Then I see an animation or text guiding me through the 4-step inhale-hold-exhale-hold process.

7.  As an AI user, I want to submit a short prompt (e.g., "I feel overwhelmed") to the AI, so that I receive a relevant comforting message.
    Acceptance Criteria:
    Given I am on the AI Support Page,
    When I enter "I feel overwhelmed" and click 'Generate Message',
    Then a short, positive, and non-clinical message appears on the screen.

8.  As a mobile user, I want to view the site on my phone, so that I can use the resource comfortably while on the go.
    Acceptance Criteria:
    Given I view the homepage on a small screen device,
    When I scroll and interact with the elements,
    Then the text and images are responsive and do not overflow the screen.

9.  As a stressed user, I want to **see a dedicated page for stress reduction tips, so that I can learn simple coping mechanisms.
    Acceptance Criteria:
    Given I am on the Stress Reduction page,
    When I read the content,
    Then I see at least three distinct, actionable tips (e.g., "Grounding Technique," "Progressive Muscle Relaxation," "Journaling").

10. As a user seeking encouragement, I want to **see a daily affirmation on the homepage, so that my day starts with a positive thought.
    Acceptance Criteria:
    Given I load the Home page,
    When the page finishes loading,
    Then a prominent, randomly selected positive affirmation is displayed.
