MoSCoW Prioritization

Priority  Features  Rationale 


MUST.  Daily Affirmations/Messages, Breathing Guide content pages, AI support message generation, Static informational pages (About, Contact/Resources). | These are the core features defined by the project background and are essential for the site's function and value proposition. 

SHOULD.  Relaxation tips content, Improved UI/UX (e.g., consistent color palette), Minimal animations for breathing guide.  Important for a good user experience, but the site would still function without them. They enhance the value. 

COULD. Dark mode toggle, Social media share buttons for affirmations, Simple search function for topics.  Nice-to-have features that can be added if time allows, but low priority. 


WON'T.  User Accounts, Login/Registration, Database/CRUD operations, Clinical assessment tools, Paid subscriptions.  Explicitly out of scope based on the project definition ("No login, no CRUD - purely informational + AI assistance").
